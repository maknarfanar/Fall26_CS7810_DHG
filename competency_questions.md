COMPETENCY QUESTIONS

Definitions:
Anomaly - a patch flagged because its reconstruction error exceeded that run’s threshold. The error and threshold are recorded.
Tile - the project uses Lidar Digital Elevation Model (DEM) tiles from OGRIP
Patch - tiles are divided into smaller patches for assessment
Training Batch - a set of patches used to train a run, selected randomly, by curation, or hybrid.
Run - one execution with a given seed and training batch.
Archaeological Reference - This will most likely be the Ohio Archaeological Inventory data but could be substituted for other data as the project matures.
Adjacent - sharing a boundary. Specify tile or patch in each CQ that uses it.
Land-use changes - currently no data is available to the project for implementing a layer for land-use of the tiles.
Candidate Patch - an anomaly that has been a human reviewed and marked for further investigation.


CQ1 Which model run flagged anomaly A, and what seed and training batch did it use?
CQ2 Which patches make up that training batch, and how was it selected (random vs curated)?
CQ3 Does anomaly A persist across runs with different seeds or training batches?
CQ4 Was the patch for anomaly A part of the training batch of the run that flagged it?
CQ5 Which reconstruction error and threshold produced the flag for anomaly A, and how was the threshold set?
CQ6 Which survey year, resolution, and CRS apply to the tile of anomaly A?
CQ7 Does anomaly A come from a survey year, resolution, or CRS different from those represented in the training batch that flagged it?
CQ8 Which non-earthwork features (roads, rails, creeks, rivers, ponds) are recorded in or adjacent to the patch for anomaly A?
CQ9 Of the known earthworks in the archaeological reference are covered by run R, which appear as anomalies and which do not?
CQ10 Which known earthworks are recovered in some runs but missed in others?
CQ11 Which anomalies are adjacent to other anomalies, suggesting a need to assess for a continuous earthwork or complex?
CQ12 Which anomalies lie in tiles adjacent to a tile containing a known linear earthwork?
CQ13 Which anomalies have been assessed, by what method, and with what outcome (confirmed, rejected, inconclusive)?
CQ14 Which anomalies have neither an independent source nor a field assessment, making them candidates for ground-truthing?
CQ15 Which rejected anomalies had a non-earthwork feature flagged in or adjacent to their patch?
CQ16 Which unassessed anomalies persist across runs and are adjacent to another anomaly?
CQ17 Does every flag have exactly one model run and one threshold?
CQ18 Does every patch belong to exactly one tile, and every tile to exactly one survey?
CQ19 What is the difference between an anomaly and a candidate patch?
CQ20 Which anomalies are in tiles threatened by planned land-use change?
